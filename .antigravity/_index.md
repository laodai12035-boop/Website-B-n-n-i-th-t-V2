# 🗂️ INDEX - Rules cho Antigravity

## 📌 CÁCH SỬ DỤNG
Khi làm việc với dự án, hãy đọc các rules theo từng phần:

### 1️⃣ Xác định task hiện tại
- **Tôi đang làm gì?** (Auth, Product, Cart, Order, Admin, ...)
- **Tôi cần code ở đâu?** (Backend, Frontend, Database, ...)

### 2️⃣ Đọc rules tương ứng

| Phần việc | Rules cần đọc |
|-----------|---------------|
| **Tổng quan** | `01-project-overview.md` |
| **Setup dự án** | `02-tech-stack.md` + `03-folder-structure.md` |
| **Code Python** | `04-coding-python.md` + `07-database.md` |
| **Code React** | `05-coding-react.md` + `10-ui-ux.md` |
| **Viết API** | `06-api-convention.md` + `08-security.md` |
| **Làm Auth** | `auth-context.md` |
| **Làm Product** | `product-context.md` |
| **Làm Cart** | `cart-context.md` |
| **Làm Order** | `order-context.md` |
| **Commit code** | `09-git-workflow.md` |

### 3️⃣ Quy tắc đọc rules
- **Mỗi task chỉ đọc 2-3 file rules** liên quan
- **Không đọc toàn bộ** để tránh nhiễu thông tin
- **Tham khảo context** nếu task đặc thù
