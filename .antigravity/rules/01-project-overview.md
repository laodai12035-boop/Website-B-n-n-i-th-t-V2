# 01 - TỔNG QUAN DỰ ÁN

## 🎯 Mục tiêu
Website bán đồ nội thất cao cấp với:
- Xem sản phẩm, tìm kiếm, lọc
- Giỏ hàng, checkout
- Quản lý đơn hàng
- Admin quản lý sản phẩm

## 👥 User Persona
- **Khách hàng**: 25-45 tuổi, mua nội thất
- **Admin**: Quản lý cửa hàng

## 🗓️ Timeline
- Tuần 1: Setup + Auth
- Tuần 2: Products
- Tuần 3: Cart
- Tuần 4: Checkout + Orders
- Tuần 5: Admin
- Tuần 6: Polish + Deploy
